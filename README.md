Studio Black – Sistema de Agendamento

Site de agendamento online para barbearia com painel administrativo para os barbeiros.

Funcionalidades

Agendamento online com escolha de barbeiro, serviço, data e horário
Confirmação via WhatsApp
Painel admin com agenda diária, histórico e KPIs
Cancelamento pelo barbeiro com aviso automático ao cliente via WhatsApp
Verificação de conflito de horários em tempo real

Tecnologias

Frontend: HTML, CSS, JavaScript
Backend: Python (Flask)
Banco de dados: MySQL

Como rodar localmente

bashpip install -r requirements.txt
python app.py
Acesse http://localhost:5000
